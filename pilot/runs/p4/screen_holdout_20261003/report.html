筛子保留 82.3% 的残余失败，最多仅直接排除其余部分。按等复核成本的候选产率估算，所需复核条数的下降代理值为 15.9%–14.1%；这不含轨迹生成、人工、反事实确认成本，不能作为每个经验证失败的成本。

h029：缺少支付工具而未指导用户付款，属于相邻伙伴能力候选，未并入手机 C。h025：agent 未调用转人工工具，却在回复里宣布转人工，随后 user 输出 TRANSFER；用户指南允许在明确被告知转人工后输出该标记，因此“早于工具调用”本身不足以判为 simulator 错误。h045：明确的 device diagnostics 缺失表述被词法筛子漏掉。
