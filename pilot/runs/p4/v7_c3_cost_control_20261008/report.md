## 运行入口

先准备（无API）：

```bash
.venv/bin/python pilot/p4_cost_control_run.py
.venv/bin/python pilot/p4_cost_control_audit.py
.venv/bin/python pilot/p4_cost_control_report.py
```

充值和填写服务商实际费率、美元限额之后，对照及每个臂使用新入口：

```bash
.venv/bin/python pilot/p4_cost_control_validate.py --run
.venv/bin/python pilot/p4_cost_control_run.py --run --arm A0 --workers 4
```

A1–A4同入口。当前`--run`在读取凭据之前就被现有余额停止标记阻断。`billing_config.json`的限额/费率留空；没有单价时拒绝发送，不猜测服务商价格。新实验不与旧实验混并成一个效率比较。
